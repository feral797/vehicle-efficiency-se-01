# Vehicle Efficiency Calculator
A simple .net CLI application built as an extension of my Software Engineering class assignment.
What does this do? It recommends the best mode of transport (Car, Bus, or Bicycle) based on your priorities.

## How to Run
### Requirements:
- [.NET SDK](https://dotnet.microsoft.com/en-us/download) installed

### Run
`dotnet run`

### Build 
`dotnet build`

## ⚠️ Notes
- All values are estimates based on average conditions
- CO₂ calculations use approximate conversion factors
- Assumes average speeds: Car (40 km/h), Bus (25 km/h), Bicycle (15 km/h)
